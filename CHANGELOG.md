# Changelog

## [1.1.2] - 2026-09-18

### Bug fixes

- Minor display issues.
- Auto display windows at block on (end of flight).
- Cache file delete at end of flight.

## [1.1.1] - 2026-09-09 (not published)

### Changed

- Minor code refactoring.

## [1.1.0] - 2026-05-08

### Added

- Flight state persistence across X-Plane restarts.
- Automatic saving of the current flight state.
- Immediate saving when a flight state changes.
- Restoration of the saved flight state when the plugin starts.
- Restoration of flight distance when monitoring is started after loading a saved flight.
- Windows 64-bit build support.
- Cross-platform Makefile with Linux and Windows build targets.

### Changed

- Reset now also deletes the saved flight state file.
- Improved handling of saved flight state restoration.

## [1.0.2] - 2021-09-09

### Modified
- Code cleanup (removed obsolete commented-out code).
- Code refactoring.

## [1.0.0] - 2021-08-13

- Initial release (V 1.0.0).
